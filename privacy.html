Pterodactyl Panel Android Privacy Policy

This privacy policy explains how Pterodactyl Panel Android collects, uses, and protects your information when you use our app.

Access

In order to use the Pterodactyl Panel Android app, the user must have a self-hosted Pterodactyl Panel instance accessible over HTTP(s) and have the login credentials for the aforementioned instance.

Use

The app allows its users to manage the admin (in a future release) and the client side of servers & other features on their self-hosted Pterodactyl Panel instance. All interactions occur directly between the user's device and the Pterodactyl Panel instance configured during login. The Pterodactyl Panel Android app does not collect any data from user interactions.

Login Data

Upon login, the Pterodactyl Panel Android app stores the user's access token on the user's device in the app's private storage. This token is used solely to keep the user logged in and avoid repeated authentication. This token is only shared with the user's Pterodactyl Panel instance to authenticate the HTTP requests.

Ads

The Pterodactyl Panel Android application does not contain any advertisement. The app only displays the data returned by the user's Pterodactyl Panel instance.

Contact

If you have any question about this privacy policy, please contact the following email address: privacy@ptero.stefdp.com.
